## Node и PR

- PR #1 уже перенесён в main отдельным коммитом без merge ancestry. Он добавил Puppeteer, package.json/lock и три Node-скрипта. Эти зависимости удалены; браузерные тестовые страницы сохранены.

Шесть проверок падали из-за неверных контрактов (swing, strength, duplicateOffset, legato, preview). Исправлены импорты, ожидаемые музыкальные результаты и слабые проверки диапазонов; humanize timing стал детерминированным.
- Legacy integration.js переведён в ES module с обычным браузерным iframe-адаптером. Он остаётся отдельным, устаревшим сценарием, не основанием для утверждения готовности всех функций.

## Исправления аудита

Удалены Node/Puppeteer manifests и четыре вспомогательных Node entrypoints. Исправлены тесты PR #2, метаданные capture, NEW mode, порядок подтверждения OPEN. Runner получает browser errors после загрузки и отключает background throttling; каждый набор использует отдельный временный профиль. Наличие исходных файлов сервера/старых браузерных артефактов не означает зависимость приложения — чужие неотслеживаемые файлы не удалялись.
