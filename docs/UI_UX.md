# UI/UX — современная 8-битная DAW

Статус: спецификация следующего рефакторинга, 2026-09-07. Это целевой интерфейс, а не описание уже внедрённого дизайна. Текущее поведение — в USER_GUIDE.md.

## Проблемы текущей композиции

Вертикальная последовательность визуализаторов, клавиатуры и множества панелей скрывает arranger ниже первого экрана. Контролы дорожек дублируются; REC в двух панелях записывает разные типы данных. Большие тексты подсказок и отдельная строка для каждой трансформации piano roll занимают место нот. Клик по ноте удаляет её, что конфликтует с ожиданием выделения. Мелкие символы и повсеместный зелёный затрудняют чтение состояний.

## Рабочая область

| Область | Содержимое и поведение |
|---|---|
| Верхняя постоянная строка | Имя проекта, состояние сохранения, undo/redo, transport, позиция bars/beats, tempo, loop, record target |
| Левый край arranger | Согласованные track headers: имя, цвет, M/S/ARM, input/monitor и компактный meter |
| Центр | Timeline; при запуске виден без прокрутки страницы; drag/drop/resize с preview |
| Правая панель | Browser либо Inspector выбранного объекта, с понятным переключением |
| Нижний dock | Piano roll, Audio editor либо Mixer; регулируемая высота, свернуть/развернуть |
| Rack workspace | Полноразмерный SID Rack, выбранное устройство и кабели; переход назад сохраняет viewport |
| Нижняя строка | Контекстная подсказка инструмента, zoom и diagnostics по запросу |

Один объект выбора связывает arranger, inspector и editor. Выбор не запускает музыку и не меняет данные; audition включается явно. Основные команды доступны и кнопкой, и клавиатурой. Для новичка — подписи; compact mode убирает повторяющийся текст, но сохраняет tooltip и aria-label.

## Визуальный язык

Сохранить pixel edges, моноширинные числовые дисплеи, phosphor-green accent, рисунок шагов и patch cables. Обычные тексты и параметры читаются без glow. Для текста — системный читаемый шрифт либо локальный ресурс, для заголовков/чисел — pixel/mono. Не загружать обязательный шрифт с внешнего сервиса.

Предлагаемые токены: canvas #0B1014, panel #141C23, raised #1C2730, primary text #E3EBE5, secondary #A2B3AC, accent #8FF078, audio #71C7E8, modulation #D69BF4, record #FF7777. Цвета проверить на реальных размерах и состояниях, не считать список токенов доказательством контраста. Интервалы по сетке 4/8 px, углы 2–4 px, чёткий border; glow только у активного индикатора. Никаких постоянно анимированных scanlines поверх текста.

Основные кнопки не меньше 32 px по высоте; touch mode — 44 px. Видимый focus ring, численный ввод в дополнение к drag knobs, wheel не меняет параметр случайно при прокрутке. Muted/armed/selected имеют знак/подпись, а не один цвет. Respect reduced-motion; масштаб браузера 200% не блокирует основные команды.

## Логика взаимодействия

- Клик выбирает, drag двигает, edge drag меняет границу; Delete или Erase удаляют. Esc отменяет незавершённый gesture.
- Одна drag-операция — одна undo transaction. Preview не пишется в autosave до commit.
- Piano roll transformations находятся в компактной панели/меню с настройками выбранной операции; пояснение рядом с ней, а не длинный постоянный абзац.
- Record показывает тип и получателя: «MIDI → Lead» либо «Audio → Input 1 / Track 3». До начала видны monitor, count-in и replace/overdub.
- STEP явно перехватывает musical keys только внутри editor scope; при текстовом вводе музыкальные команды отключены.
- Save status различает изменения, сохранение, сохранено и ошибку. Project и Rack patch имеют разные названия команд.
- Пустой проект предлагает Add instrument / Import audio / Record audio. Отсутствующий clip selection предлагает выбрать или создать клип.

## Приёмка по сценариям

1. На 1366×768 пользователь видит transport, дорожки и timeline без прокрутки страницы.
2. Создаёт мелодию, выбирает ноту без удаления, исправляет drag и отменяет одной командой.
3. Импортирует audio, добавляет clip, находит offset/fades в inspector и понимает, какой источник используется.
4. Записывает take и однозначно видит дорожку, тип записи, monitor и count-in.
5. Переключается Rack ↔ Arrange, не теряя выделение и масштаб.
6. Работает клавиатурой и при 200% zoom; контекстные shortcuts не конфликтуют с именованием и STEP.

Перед внедрением закрепить baseline screenshot и реальные сценарии текущей версии; затем проверять срезы workspace → commands/focus → editors → mixer → visual polish. Не начинать с одновременной переписи всего CSS и scheduler.
