# SID Studio — руководство пользователя

Редакция 2026-09-13: main `96d7fb1` и локальный первый этап UI-вехи M3. Описывает текущую программу; будущие возможности находятся в [TODO](TODO.md). Навигация русская, часть музыкальных команд пока английская. Это развивающаяся web-DAW с SID-вдохновлённым синтезатором, а не точная эмуляция оригинального чипа.

## Запуск и первый звук

Из папки проекта запустите `python serve.py . 3000` либо `pwsh -File tests/serve-ps.ps1` (порт 3100, без Python). Откройте соответственно http://localhost:3000 или http://localhost:3100. Приложение не требует npm. Аудио запускается после действия пользователя. Для записи разрешите доступ к микрофону, когда браузер запросит его.

1. Во вкладке «Дорожки · шаги» уже есть Track 1. Нажмите несколько клеток 16-шаговой сетки; при узком окне сетка прокручивается горизонтально.
2. Нажмите PLAY. BPM задаёт скорость, STOP останавливает воспроизведение. Кнопка LOOP в транспорт-баре включает повтор региона (locators). Кнопка METRO включает метроном на время воспроизведения (клик на каждую четвертную долю).
3. Сразу после добавления ноты измените поля ноты и длины в строке трека (повторный клик по заполненной клетке удаляет ноту): они относятся к выбранному шагу. Без выбранной клетки это значения для новых нот. Длина измеряется шестнадцатыми.
4. ADD TRACK добавляет ещё один синтезаторный трек. Для каждой дорожки можно выбрать waveform и filter.
5. Отмените правку кнопкой ↶; ↷ возвращает её. Ctrl/Cmd+Z и Ctrl/Cmd+Shift+Z работают для истории музыкальных правок. В текстовом поле сохраняется обычная отмена ввода.

Звук экранной клавиатуры также может идти в модульный рэк, если в нём есть подключённые генераторы. Рэковые пресеты не меняют инструмент дорожки.

## Где что находится

| Область | Для чего нужна |
|---|---|
| Шапка проекта | Новый / Открыть / Сохранить / Сохранить как, ссылка на руководство |
| Верхний транспорт | MIDI REC, Play/Pause/Stop, Panic/Cancel, Undo/Redo, BPM, loop/metro, режимы записи и playback, WAV |
| «01 / Аранжировка» | Timeline с дорожками, клипами, границами и маркерами — виден сразу |
| «Дорожки · шаги» снизу | RECORDER: треки, ARM, step grid, MIDI-канал, инструменты, inserts |
| «Ноты · аудиоклип» снизу | PIANO ROLL / DRUM GRID или параметры выбранного аудиоклипа |
| «Клавиатура · анализ» снизу | Осциллограмма, спектр, нота и игра мышью C2–B4 |
| «Аудиофайлы» справа | MEDIA POOL: импорт, прослушивание и добавление аудио |
| «Запись аудио» справа | INPUT: микрофон/вход, мониторинг и отдельный audio take |
| «02 / SID Rack» | PRESETS и модульный синтезатор с его патчами |

Ползунок «Высота» меняет размер нижнего редактора от 220 до 600 px. Вкладки не пересоздают панели: настройки, содержимое и прокрутка сохраняются при переходе между ними. Новый выбор клипа в аранжировке открывает «Ноты · аудиоклип». На узком экране боковая панель переходит вниз. Вкладки переключаются мышью, а при фокусе на их заголовках — ←/→, Home/End. Высота и выбранная вкладка пока не сохраняются после перезагрузки.

В строке под транспортом отображаются состояние сохранения и **MIDI REC → имена armed-дорожек**, либо активная дорожка, если ARM нигде не включён. Фильтрация по MIDI-каналу остаётся в настройках дорожек; строка не показывает её отдельно. Индикатор `001 : 1` — такт и доля при 4/4. MIDI REC не запускает запись микрофона: для неё откройте «Запись аудио».

Команды arranger, редактора нот и удаления соединений rack относятся к области с фокусом: сначала щёлкните нужный редактор. Скрытые области их не выполняют. Фокус выделен рамкой; текстовые поля и заголовки вкладок не запускают эти команды. Это ещё не полная унификация всех горячих клавиш.

## Дорожки и эффекты

Выберите строку трека перед записью или добавлением клипа. ARM подготавливает трек к записи нот. MUTE/M выключает звук, SOLO/S оставляет выбранные solo-треки. MNT управляет живым мониторингом; выключенный мониторинг не мешает захвату нот на armed-треке.

Двойной клик по имени позволяет переименовать трек: Enter подтверждает, Esc отменяет. ▲/▼ меняют порядок. Цветовая кнопка задаёт цвет; границу дорожки в arranger можно тянуть по высоте. Кнопка сворачивания уменьшает отображение. Связь folder существует в модели, но полноценный интерфейс создания групп и групповой микшер ещё не готов.

INS открывает delay/reverb insert chain дорожки. Добавьте эффект и настройте доступные параметры. Mute/solo и inserts применяются также к аудио этой дорожки. Отдельной микшерной консоли, pan, шин и sends пока нет.

METRO включается для текущей сессии и пока не восстанавливается после загрузки проекта. **Pause** останавливает звук с сохранением позиции, **Play** продолжает, **Stop** возвращает позицию к началу. Во время MIDI-записи Pause отключена: используйте Stop для завершения либо Cancel для отмены тейка. Audio take имеет собственные кнопки записи/остановки справа; общий Pause не является паузой аудиотейка.

## Работа с клипами

Кнопка `+ clip` добавляет клип на активный трек после существующих. Клик выбирает клип для нижнего редактора. Ctrl+click включает множественный выбор, Shift+click — диапазон. Перетаскивание двигает клип с привязкой; края меняют длину. Доступны Split (S), Duplicate (D), Repeat (L, три повторения) и Delete. Клавиши относятся к контексту arranger.

`+ mrk` добавляет маркер на текущей позиции. Клик по маркеру переносит курсор, × удаляет его. Кнопка loop и границы на ruler задают диапазон повтора. `+ end` ставит конец проекта на курсор; воспроизведение останавливается там. Масштаб меняется кнопками −/+; длинный проект прокручивается горизонтально.

В верхнем транспорте выберите PLAYBACK → **SONG** или **PATTERN**. В SONG все MIDI-клипы играют один раз по timeline, включая клипы на нуле. Перенос клипа вправо оставляет тишину перед ним; его удаление не оставляет отдельную звучащую сетку. Ноты ограничиваются правой границей клипа. Новые проекты начинаются в SONG.

В PATTERN повторяется выбранный step-клип в пределах 16-шагового цикла; остальные клипы идут линейно. Если явно ничего не выбрано, используется клип на нуле либо первый доступный. Старые проекты без поля режима открываются в PATTERN, чтобы не менять прежнее звучание. Переключение режима останавливает playback, сохраняется с проектом и отменяется через undo. Диапазон loop на ruler — отдельный механизм; согласование всех seek/loop-режимов с аудио ещё в работе.

Step grid редактирует выбранный клип по его ID, независимо от позиции в песне. Выберите клип в ARRANGER либо в списке под названием трека слева от сетки. Сетка показывает первые 16 шагов относительно начала этого клипа; список указывает его имя и такт (пока 4/4). Выбор в списке задаёт step-клип, который также используется режимом PATTERN и записью MIDI. Сам по себе этот список не переключает Piano Roll. После загрузки выбор возвращается к клипу на нуле, а если такого нет — к первому клипу дорожки. Первая правка пустой сетки создаёт реальный клип. Правка шага сохраняет остальные ноты, их velocity, точные старты и длительности. Если в шаге аккорд, клетка показывает последнюю ноту: изменение полей затрагивает её, toggle удаляет только её и открывает следующую. Для всего аккорда удобнее piano roll. Undo восстанавливает исходные события, а не их упрощённое изображение в сетке. Redo сохраняет исходную цель команды даже после переключения на другой клип. CLR очищает MIDI-ноты выбранного step-клипа, сохраняя остальные клипы и его аудиослой.

## Piano roll и drum editor

Выберите MIDI-клип в ARRANGER. Клик по пустой клетке добавляет ноту с прослушиванием; drag ноты меняет позицию/высоту, drag края — длительность. Сейчас короткий клик по существующей ноте **удаляет** её. Для группового выбора протяните рамку, затем двигайте группу или нажмите Delete. Ctrl+D дублирует выбранные ноты. Velocity регулируется перетаскиванием столбика под нотами.

Snap: 1/16, 1/8, 1/4 или off. Масштаб: −/+, Ctrl+колесо. Видимый диапазон piano roll пока ограничен; MIDI-вход сам по себе принимает номера 0–127.

Раскройте «Обработка нот и подсказки» под заголовком редактора. Здесь находятся следующие операции; по умолчанию панель свёрнута, чтобы оставить место сетке.

| Операция | Действие |
|---|---|
| Q / quantize | Привязать старты нот, с strength и swing |
| T / transpose | Сдвинуть высоту в полутонах в пределах текущего диапазона редактора |
| L / legato | Продлить ноты до следующего старта |
| F / fixed len | Сделать длину равной шагу snap |
| H / humanize | Случайно сдвинуть время и velocity в заданных пределах |
| ▶ рядом с операцией | Прослушать результат без применения |

Операция действует на выделение, либо на все ноты при пустом выделении. Применение можно отменить. Humanize использует случайные значения: отдельный preview не гарантирует ту же случайную вариацию при последующем применении.

STEP включает ввод с компьютерной клавиатуры: `Z S X D C V G B H N J M` — C3–B3; `Q 2 W 3 E R 5 T 6 Y 7 U` — C4–B4. Каждая нота двигает курсор на snap; ←/→ перемещают его, Backspace стирает с шагом назад, Esc выходит. Не используйте в этом режиме буквы как команды arranger.

DRUM переключает отображение на ряды C3–B3. Подписи Kick/Snare/HiHat — ориентиры сетки; они не означают наличие отдельного набора сэмплов ударных. Звучит инструмент дорожки.

Предпрослушивание преобразований сохраняет аккорды, точные длительности и off-grid позиции также в клипе на нуле; оно не записывает изменения. Для случайного Humanize последующее применение генерирует новые случайные отклонения.

## Запись MIDI и экранной клавиатуры

1. Выберите трек и ARM. Если armed-треков нет, REC подготавливает активный.
2. Выберите клип для каждого armed-трека. OVERDUB добавляет ноты; REPLACE очищает MIDI-ноты выбранного клипа перед записью.
3. Нажмите REC, играйте, затем STOP. Несколько armed-треков могут записываться одновременно. Завершённый тейк отменяется одной командой Undo; CANCEL отменяет незавершённый тейк, включая очистку REPLACE.
4. REC Q применяет quantize при завершении записи. Исходные старты сохраняются в данных тейка; отдельной пользовательской команды восстановления исходного тайминга пока нет.

В SONG запись использует абсолютную позицию песни и размещает ноты относительно выбранного клипа. Ноты могут удерживаться через несколько циклов. Во время записи не переключайте, не перемещайте и не удаляйте клип: получатель пока определяется при коммите, а не фиксируется при старте. Добавление записанного материала в OVERDUB сохраняет прежние ноты. Для REPLACE и параллельных правок сохраняйте копию проекта заранее.

Для внешней клавиатуры нажмите MIDI CONNECT, затем выберите устройство в списке ALL MIDI. В строке трека выберите Omni либо канал 1–16. При наличии armed-треков вход направляется в подходящие по каналу armed-треки; иначе — в активный трек при совпадении канала. Key-up освобождает первоначального получателя даже после смены выбора.

Есть live pitch bend ±2 полутона, CC1 (cutoff), CC7 (volume), CC64 (sustain). Channel pressure влияет на тембр, program change выбирает waveform. PANIC останавливает голоса, сбрасывает live expression и закрывает открытые ноты тейка. В записи сохраняются снимки bend/mod/pressure при начале ноты, но не непрерывные движения контроллеров. Возврат к нейтральному состоянию при playback/chase ещё неполон; для надёжного переноса сложного исполнения это ограничение существенно. MIDI file import/export пока отсутствует. Поддержка MIDI зависит от браузера.

## Импорт и аудиоклипы

В MEDIA POOL нажмите IMPORT или перетащите файл. Расширения WAV/MP3/OGG/FLAC/AIFF принимаются интерфейсом; фактическое декодирование зависит от браузера. После импорта доступны metadata, waveform preview, прослушивание ▶/■ и +CLIP для активной дорожки. Исходные данные хранятся в IndexedDB этого браузерного origin.

Выберите аудиоклип: нижняя панель показывает источник, offset/gain/fade controls. Отсоединение audio reference оставляет MIDI-ноты клипа. Duplicate/repeat сохраняют ссылку на исходное аудио; split сдвигает source offset правой части. Исходный файл не переписывается. MIDI trim/split также используют окно исходных событий: скрытые за границей ноты не удаляются. Для Duplicate/Repeat уже обрезанного MIDI-клипа есть известный риск сброса source offset — проверяйте результат и пользуйтесь Undo.

Удаление из MEDIA POOL запрещено, пока источник используется клипом текущего проекта. Учёт ссылок undo-истории ещё не завершён: удалённый из пула источник нельзя считать защищённым обычной отменой удаления клипа. Для отсутствующего media есть locate/replace; храните оригиналы отдельно.

## Запись микрофона или внешнего входа

1. В INPUT обновите список ⟳ и выберите устройство. Разрешите доступ браузеру.
2. Проверьте meter. MON включает прослушивание входа через выход; по умолчанию оно выключено. При работе с микрофоном используйте наушники, чтобы избежать обратной связи.
3. Выберите активный трек, задайте позицию и нажмите ● в INPUT. Это запись **аудио**, отдельная от REC нот в RECORDER.
4. Нажмите ● снова: take добавится в MEDIA POOL и станет аудиоклипом.

Count-in задаёт предварительный отсчёт. IN/OUT и PUNCH ограничивают область записи. Поправка latency в миллисекундах добавляется к оценке выходной задержки браузера; это приближённая компенсация, а не измеренная round-trip калибровка. Проверяйте выравнивание take на слух. Автосинхронизация всех режимов записи с транспортом и полноценные take lanes/comping ещё развиваются.

## Модульный SID Rack

Перетащите OSC/FILTER/ADSR/EFFECTS/LFO/MIXER/SPLITTER/SEQ из COMPONENTS. Соедините выход источника со входом следующего модуля или MASTER OUT. Escape либо клик на пустой рэк отменяет выбор порта. Удаляйте компонент его ×.

Минимальный тракт: OSC → MASTER OUT. Для огибающей и тембра добавьте filter и ADSR. LFO-соединение с frequency/cutoff является модуляцией и отображается розовым. Splitter предоставляет выходные каналы. Синтезаторы дорожек полифонические (8 голосов), классический rack остаётся mono last-note.

SEQ-модуль следует общему транспорту: глобальные Play/Stop/Seek запускают, останавливают и переставляют паттерн, темп берётся из проекта (свой BPM-ввод при этом отключён). Высота осцилляторов переключается точно в момент запланированной ноты. Кнопки PLAY/STOP на самом модуле работают автономно, если транспорт остановлен.

BASS/LEAD/PAD/DRUM/ARP и другие встроенные пресеты применяют параметры к существующим модулям соответствующих типов. SAVE/LOAD/DEL управляют пользовательскими rack-пресетами. SAVE PATCH/LOAD PATCH экспортируют и загружают JSON **только рэка**, не всей песни и не аудиофайлов.

## Сохранение и WAV

Проект (rack, tracks, clips, markers, tempo, loop) автоматически сохраняется локально в этом браузере. Статус под панелями: `● Есть несохранённые изменения…`, `Сохранено ЧЧ:ММ:СС`, ошибка сохранения. Неизменённое состояние не перезаписывается, последние 5 сохранений держатся как резервные копии (восстановление при битой записи — автоматически со статусом). Аудио хранится отдельно от JSON в IndexedDB. Адрес, порт и браузерный профиль важны: localhost:3000, localhost:3100 и 127.0.0.1 — разные хранилища. Очистка данных сайта может удалить проект и media. Журнал save-status хранится в памяти и не является долговечной историей изменений.

Если сохранение недоступно или сохранена более новая версия формата, сообщение появляется над панелями; защищённый снимок не заменяется автоматически. Сообщение не означает, что текущие изменения уже сохранены.

NEW / OPEN / SAVE / SAVE AS переносят весь проект одним файлом `.sidproject.json`: песня (rack, tracks, clips, markers, tempo, loop) плюс всё аудио из пула и клипов. SAVE PATCH по-прежнему сохраняет только rack. Автосейв (localStorage + IndexedDB) не покидает этот браузер — для переноса в другой браузер или профиль используйте SAVE, затем OPEN там. При открытии отсутствующее аудио перечисляется в статусе (такие места молчат), повреждённые файлы отбрасываются сверкой hash. NEW создаёт пустой SONG-проект и не удаляет аудиофайлы из браузера, только отвязывает их от проекта. Перед NEW/OPEN сохраняйте важные изменения вручную: предупреждение пока учитывает не все правки rack/live/media вне истории. SAVE запускает скачивание; проверьте наличие файла, поскольку приложение не подтверждает завершение записи на диск.

WAV в RECORDER записывает **четыре такта живого master** в stereo PCM 16-bit. Экспорт занимает реальное время и использует текущий микс. Это ещё не offline render всей песни: нет выбора диапазона, stems, гарантированного хвоста reverb или экспорта 24/32-bit. Не редактируйте и не играйте поверх микса во время записи WAV.

## Ограничения текущей версии

Полного микшера с pan/шинами/sends, automation lanes, comping и offline-экспорта всей песни пока нет. Новый dock и отдельный SID Rack — первый этап UI: прежние жесты Piano Roll, часть сокращённых подписей и настройки инструментов ещё требуют переделки. SID — стилистика и приближённый синтез, не точная эмуляция 6581/8580. Голоса имеют исправленный release и базовые звуковые проверки, но физические устройства, большие проекты и все браузеры ещё не прошли полную приёмку. Порядок развития — в [TODO](TODO.md).

## Если что-то не работает

- Нет звука: выполните действие пользователя, проверьте waveform, подключения rack, M/S и monitor, затем выходную громкость устройства.
- MIDI не доступен: проверьте поддержку браузера, разрешение и MIDI channel/ARM выбранного трека.
- Нет входного аудио: обновите список устройств, проверьте разрешение и indicator INPUT; MON управляет прослушиванием, а не самим разрешением записи.
- После смены адреса пропал проект: вернитесь на тот же host/port и браузерный профиль.
- Отсутствующий media: используйте locate/replace и исходный файл; JSON патча не содержит записей.

### Строгая проверка проекта при открытии

OPEN, восстановление autosave и recovery проверяют документ до изменения текущего проекта. Ошибочные числа, диапазоны, повторяющиеся ID, отсутствующие ссылки и неподдерживаемые версии вызывают ошибку с путём поля. Значения по умолчанию добавляются только для отсутствующих полей. Старые grid/rt и раздельные ключи localStorage поддерживаются через миграцию.

Рэк и голоса нового проекта сначала создаются отдельно. Если проверка или подготовка аудиоустройства не удалась, текущий проект и его история сохраняются. После успешной подготовки состояние заменяется синхронно и история сбрасывается. Технический контракт и границы гарантии описаны в [справочнике разработчика](DEVELOPMENT.md).

Отсутствующий Blob при корректной записи в manifest по-прежнему допускается: portable bundle сообщает о потерянном media. Ссылка клипа на hash, которого нет в manifest, считается повреждением проекта.
